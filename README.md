## 🛠️ Configuração Inicial (Subir o projeto via Docker)

1. **Gere o arquivo `.env` a partir do modelo:**
   ```bash
   cp .env.example .env
   ```

2. **(Opcional):** Abra o arquivo `.env` gerado e ajuste as variáveis (como senhas e portas) de acordo com a sua preferência.

3. **Suba o ambiente:**
   ```bash
   docker compose up -d
   ```
